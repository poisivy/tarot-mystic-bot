# 🔮 Telegram Бот «Tarot Mystic Bot»

Развлекательный Telegram-бот, который имитирует магические практики: гадание на картах Таро, расчёт совместимости, построение натальной карты и ответы на вопросы о будущем с помощью генеративных нейросетей.

> ⚠️ **Важное предупреждение:** Бот создан **исключительно в развлекательных целях**. Все предсказания, интерпретации карт, расчёты совместимости и натальных карт генерируются случайным образом или с помощью ИИ и **не являются профессиональными консультациями**. Не принимайте серьёзных жизненных решений на основе ответов этого бота.

## ✨ Возможности бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветственное сообщение |
| `/ask` | Задать любой вопрос о будущем. Бот использует YandexGPT для генерации мистического ответа |
| `/compatibility` | «Узнать совместимость» по фото избранника. Выдаёт случайное число от 0 до 100 и комментарий от ИИ |
| `/natal_chart` | Построить натальную карту по дате и времени рождения. Данные парсятся с сайта geocult.ru |
| `/tarot` | Расклады Таро:<br>• Карта дня<br>• Прошлое, настоящее и будущее<br>• Расклад на ситуацию (7 карт)<br>• Лемниската — расклад на любовь (8 карт) |

## 🧠 Техническое устройство

### Используемые технологии

- **Python 3.8+** — основной язык программирования
- **pyTelegramBotAPI** — взаимодействие с Telegram Bot API
- **YandexGPT API** — генерация мистических предсказаний и интерпретаций
- **BeautifulSoup4** — парсинг HTML для получения натальных карт
- **Pillow (PIL)** — обработка и склейка изображений карт
- **Requests** — HTTP-запросы к API и сайтам

### Как это работает

#### 1. Генерация ответов (YandexGPT)
Для каждого типа запроса используется свой системный промпт:
- `"Ты мудрая гадалка, помогающая узнать судьбу"`
- `"Ты интерпретируешь результаты раскладов таро"`
- Ответы ограничены 200–300 токенами

#### 2. Натальная карта
- Отправка запроса на `geocult.ru` с параметрами даты/времени/места
- Парсинг двух изображений (карта и аспекты)
- Склейка изображений в одно
- Отправка пользователю с кнопкой-ссылкой на подробный разбор

#### 3. Расклады Таро
- Словарь `dict_tarot` содержит 78 карт (старшие и младшие арканы)
- Случайный выбор карт в зависимости от расклада
- Динамическая склейка изображений в коллажи
- Отправка изображения + текстовой интерпретации от ИИ

#### 4. Совместимость
- Генерация случайного числа от 0 до 100
- Запрос к YandexGPT для создания "магического" комментария
